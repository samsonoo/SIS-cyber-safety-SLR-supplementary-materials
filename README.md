# Supplementary materials for SIS cyber-safety systematic literature review

This repository contains supplementary materials for the manuscript on cybersecurity impacts on the reliability and safety performance of Safety Instrumented Systems (SIS).

## Contents

The Excel workbook in `data/` contains the following sheets:

| Sheet | Description |
|---|---|
| Search Result | Raw database search results exported from the selected digital libraries |
| SLR_Screening | Screening decisions across duplicate removal, title, abstract, and full-text stages |
| Data_Extraction | Extracted study-level data for the retained primary studies |
| Corpus | Binary coding matrix used for taxonomy-based analysis |
| Taxonomy | Full taxonomy, including groups, categories, tags, keyword triggers, frequencies, and study IDs |
| Tables_and_Figures_Data | Data used to generate selected manuscript tables and figures |
